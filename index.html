THE PROBLEM

校舎が増えるほど、本部の目が届かなくなる。

1校舎なら塾長が全部を見られた。けれど2校舎目を超えたあたりから、経営は「教室長への信頼」だけで回り始める。それは強さではなく、見えていないだけかもしれません。

  • —各校舎の今月の生徒数と売上を、すぐに数字で言えない
  • —退塾が出てから「実は先月から面談が減っていた」と後で知る
  • —校舎ごとにExcelの様式がバラバラで、集計するだけで本部の半日が消える
  • —連絡はLINEグループに流れて埋もれ、誰がどの数字を持っているのか曖昧になる
  • —教室長が代わると、その校舎のことが誰にも分からなくなる

THE SHIFT

教室長任せの経営から、本部が見える経営へ。

多校舎塾マネジメントBASEがやることは、ひとつ。バラバラだった各校舎の情報を、本部が見られる1つの土台にまとめることです。

これまで

各校舎のExcelとLINE頼り

本部は報告を待つしかなく、判断はいつも後手に回っていました。数字は校舎ごとに散らばり、全体像は誰かに聞かないと見えない。

これから

全校舎の情報が、1つのNotionに集約

生徒・売上・退塾・コマ稼働が1か所に集まる。本部は報告を待たず、今この瞬間の数字を自分で見て判断できる。感覚や報告に頼る経営から、数字で意思決定する経営へ。

VALUE 01

全校舎の今が、1画面でわかる。

生徒数・売上・退塾率・コマ稼働率を本部でまとめて見る。教室長の報告を待たず、本部が即座に把握できる状態が、多校舎経営の最初の土台です。

「A校は今月どうだ」「B校の稼働は埋まっているか」。これまで電話やLINEで聞いて回っていた数字が、開けばそこにあります。どの校舎が伸びていて、どの校舎が落ちているのか。並べた瞬間に、本部が次に何をすべきかが、感覚ではなく数字で決まります。

生徒一人ひとりの情報、講師ごとの担当コマ、請求の状況まで、すべて同じNotionの中でつながっています。

VALUE 02

退塾を、増える前に止める。

退塾は突然ではありません。欠席が増える、成績が下がる、面談が途絶える。兆候は必ず数字に出ています。

成績が下がり始めた生徒、欠席が増えてきた生徒、面談で気になる発言があった生徒。こうしたサインは現場では拾えても、本部までは届きません。出欠・成績・面談記録といった日々のデータをもとに、退塾につながりそうな兆候を早い段階で拾い上げ、本部と教室長が手遅れになる前に共有できる状態を目指します。

退塾が1人増えれば、その校舎の年間売上はその分だけ確実に減ります。辞めてから対応するのではなく、辞めそうな段階で動ける。それが多校舎全体の数字を守ります。

VALUE 03

校舎を増やしても、崩れない。

拡大のたびに運営がゼロから始まるなら、それは仕組みではなく属人化です。

多くの塾で、出店のたびに管理がゼロから組み直しになります。新しい教室長の我流が始まり、様式も運用も校舎ごとに枝分かれしていく。これが拡大のたびに経営が崩れる正体です。

多校舎塾マネジメントBASEなら、すでに回っている校舎の仕組みをそのまま複製して新校舎を立ち上げられます。生徒管理も、時間割も、請求も、講師の担当割りも、同じ型でそのまま立ち上がる。教室長が代わっても、校舎が増えても、本部のガバナンスが効いたまま運営が続きます。

FAQ

よくあるご質問

ご相談前に経営者から多くいただく質問をまとめました。

Q.大手の塾管理システムと何が違いますか。
大手は多機能ですが月額数万円からと高額で、中小塾には使わない機能が多くなりがちです。多校舎塾マネジメントBASEはその3分の1以下の価格で、御塾の業務に合わせて必要な分だけ自由に組めます。多機能で使われないシステムではなく、自塾に合わせて育てられる基盤です。
Q.Notionを使ったことがなくても運用できますか。
はい。設計から運用サポートまで行うので、Notionの知識は不要です。教室長や講師がそのまま使える形でお渡しし、難しい操作は必要ありません。
Q.今使っているExcelのデータは移せますか。
移せます。現在の管理表を見せていただければ、生徒・講師・売上の必要なデータを整理してNotionに取り込みます。ゼロからの入力し直しにはなりません。
Q.1校舎だけでも導入できますか。
可能です。ただし本領を発揮するのは2校舎以上で、本部が全校舎をまとめて見たいときです。1校舎で塾長が全体を把握できている場合は、無理におすすめしません。
Q.費用はどのくらいですか。
校舎数や運営体制によって変わります。無料相談で御塾の状況をうかがった上で、最適な形をご提案します。大手の塾管理システムの3分の1以下を目安にお考えください。
